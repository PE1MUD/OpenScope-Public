PM5644 G924 ROM SETS

Put BOTH V1 and V2 EPROM dumps in this single directory.

OpenScope choices:
  16x9_v1.ini   - G/924 V1
  16x9_v2.ini   - G/924 V2

V2 contains only eight changed EPROMs. It intentionally reuses the V1
B-Y ROMs:
  EPROM_4008_002_00621_CSUM_06E1.BIN
  EPROM_4008_002_00631_CSUM_FFB8.BIN

Both revisions use the same four field tables and the same generic
PM5644_2BYTE_20MHZ decoder.
